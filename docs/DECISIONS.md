# Nhật ký quyết định — MỤC LỤC

Nhật ký đã tách làm 3 file để mỗi phiên chỉ đọc phần cần. **Số D giữ nguyên**, không đổi nghĩa. Không tự đổi quyết định đã chốt.

| Làm việc về | Đọc file | Gồm |
|---|---|---|
| Nền tảng, gói/giá, tài khoản, hạ tầng | [DECISIONS_CHUNG.md](DECISIONS_CHUNG.md) | D1–D9, D11–D13; cách triển khai D8, D11–D14; cảnh báo tên miền (D13) |
| **App** quản lý cơ sở + trang quản trị nền tảng | [DECISIONS_APP.md](DECISIONS_APP.md) | D10, D14–D56; giả định A1–A43 |
| **Website** + quản trị website | [DECISIONS_WEB.md](DECISIONS_WEB.md) | D57–D73; giả định A44–A48 |

Quyết định mới: ghi vào file của mảng đang làm; nếu ảnh hưởng cả hai thì ghi vào CHUNG và nhắc ở file còn lại.
